# Cinema APP

Cinema Hub is a desktop cinema booking application that allows users to explore movies, watch trailers, book tickets, and manage their bookings in a simple and user-friendly way. The project focuses on good UI/UX practices and provides a smooth booking experience.

---

## Project Overview

This project was created as part of my final coursework for my UAL Level 3 Software Development Year 1 qualification. It demonstrates my skills in:

- UI/UX research and design
- Wireframing and prototyping
- C# application development
- Iterating features based on user feedback

The app is inspired by real cinema platforms such as Odeon, with a strong focus on usability and visual consistency.

---

## Features

- User sign up and sign in system  
- Membership selection  
- Browse available movies  
- Watch movie trailers  
- Ticket booking system  
- Interactive seat picker  
- View past bookings stored in a ticket database  
- Dark mode and light mode  
- Clean and consistent UI design  

---

## Research and Design

- **Primary research:** Competitor analysis of cinema apps and websites  
- **Secondary research:** UI/UX articles and case studies  
- **Design tools:** Figma (wireframes and prototypes)  
- **Design focus:** Accessibility, clarity, and ease of use  

User feedback was collected and used to refine layout, navigation, font sizes, and features.
