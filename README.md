# Cinema Hub App

Cinema Hub is a C# .NET desktop booking application developed as part of my UAL Level 3 Software Development coursework. The project demonstrates practical experience in application design, event-driven programming, and user-focused development.

## Key Features
- Browse available movies and showtimes  
- Ticket booking and seat selection  
- Membership selection and booking history  
- Light and dark mode interface  

## Technical Overview
- Built using **C#** and **.NET (Windows Forms)**
- Event-driven architecture
- CSV-based data storage
- UI designed and prototyped in **Figma**
- Features refined through testing and user feedback

## Skills Demonstrated
- Problem solving and logical thinking  
- Translating designs into working applications  
- Testing, debugging, and iteration  
- Clear and maintainable code structure  

## How to Run
1. Open the solution in **Visual Studio**
2. Build and run the application
